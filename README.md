# StreamCore

A Python microservices project with database operations and Kafka simulation.

## Project Structure

```
StreamCore/
├── services/           # Microservices
├── shared/             # Shared libraries and utilities
├── infrastructure/     # Kafka simulation, database configs
├── tests/              # Test suites
├── docker/             # Docker configurations
└── scripts/            # Utility scripts
```

## Tech Stack

- **Language**: Python 3.11+
- **Database**: PostgreSQL
- **Message Broker**: Kafka (simulated)
- **Testing**: pytest

## Getting Started

```bash
# Create virtual environment
python -m venv venv
source venv/bin/activate  # Linux/Mac
# or
.\venv\Scripts\activate   # Windows

# Install dependencies
pip install -r requirements.txt
```
